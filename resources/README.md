# Resources

This directory tracks curriculum, assessment, pedagogy, animation, and dataset sources.

## Policy

Resources are separated into:

- **preserved snapshots** — concise notes about external repositories and their intended role;
- **official source links** — authoritative Bulgarian pages and documents;
- **reference-only sources** — useful for research but not copied;
- **download queue** — documents requiring retrieval or licence confirmation.

## Current folders

- `catalog/` — source and licensing catalogues.
- `official-bulgaria/` — authoritative Bulgarian source index.
- `snapshots/` — concise snapshots of external repositories and intended role.

## Important

This repository does not assume that publicly accessible educational material is commercially reusable. Every content source requires an explicit ingestion decision.
