# Learning System

## Purpose

The application must always be able to answer five questions:

1. What is the learner expected to know?
2. What does the learner currently know?
3. How does this learner learn most effectively?
4. What should the learner do next?
5. What evidence shows that learning occurred?

These questions are represented by five connected models.

## 1. Expected Competency Model

This is the target map. It defines competencies expected in Bulgarian grades 4–8, mathematical domains and topics, micro-skills, prerequisite relationships, evidence of mastery, and school or exam expectations.

## 2. Current Mathematical State

For each skill, distinguish:

- mastered;
- developing;
- missing;
- forgotten;
- blocked by a prerequisite;
- conceptually understood but not fluent;
- procedurally successful but not conceptually understood;
- successful only with support;
- independently transferable.

The learner should never be reduced to a single grade label or broad percentage.

## 3. Learner Persona Model

This records how the learner learns: useful representations, explanation length, effective hints, step size, frustration patterns, motivation, interests, and preferred interaction type.

## 4. Active Learning Plan

This contains the immediate target, missing prerequisites, review items, next candidate skills, current teaching strategy, current support level, and the reason each next step was selected.

## 5. Learning Evidence and Progress

This records questions attempted, widgets used, hints requested, misconceptions, successful corrections, independent successes, delayed retention, and transfer.

## Adaptive loop

```text
Observe interaction
→ evaluate mathematical meaning
→ update learner state
→ update personalization evidence
→ select the next objective
→ select a teaching strategy
→ render a widget or explanation
→ collect new evidence
```

## Product outcome

```text
Expected knowledge
− Current reliable knowledge
= Personalized learning work
```

That work is ordered by prerequisites, urgency, learning value, emotional difficulty, and current school requirements.
