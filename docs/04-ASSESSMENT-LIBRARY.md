# Assessment Library

## Purpose

The assessment library is a structured collection of questions, interactive tasks, exams, and generators connected to the competency graph.

## Assessment modes

- **Diagnostic:** locate the learner's actual starting point.
- **Prerequisite check:** determine which earlier skill blocks a target skill.
- **Guided practice:** teach and assess within the same interaction.
- **Mastery check:** confirm independent performance through varied evidence.
- **Retention check:** verify knowledge after time has passed.
- **Transfer check:** verify use in a new format or context.
- **Grade readiness:** measure readiness for the next Bulgarian grade.
- **NVO preparation:** match official reasoning demands and answer formats.
- **Challenge mode:** use olympiad-style reasoning for ready learners.

## Item quality

Every item or template should eventually declare:

- target skill;
- prerequisites;
- purpose;
- difficulty;
- answer format;
- correct answer;
- validation method;
- misconceptions tested;
- support available;
- widget type;
- expected mastery evidence;
- source and licence;
- reviewer status.

## Source policy

The final bank combines:

1. original, teacher-reviewed templates;
2. deterministic parameterized generators;
3. openly licensed material where commercial reuse is allowed;
4. official Bulgarian exams as calibration and reference;
5. licensed publisher content only under explicit agreement.

Grade 4 and grade 7 NVO are central calibration sources. Grades 5, 6, and 8 require original entry, unit, end-of-grade, and readiness assessments.

## Assessment principle

A correct answer is evidence, not proof of mastery. Consider independence, hints, response time, answer changes, confidence, representation, varied examples, delayed retention, and transfer.
